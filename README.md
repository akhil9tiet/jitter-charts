# Jitter Charts

An animated chart showcase built with React, TypeScript, D3, and Vite. It includes a story-arc line chart, an annotated quarterly line chart, and a two-series bar chart.

## Getting Started

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` type-checks the application and creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint.

## Charts

Chart implementations live in `src/AnimatedLineChart`, `src/AnimatedChartAnnotated`, and `src/BarChart`.
